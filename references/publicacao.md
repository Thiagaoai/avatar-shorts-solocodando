# Publicação

Escreva `publicacao.md` no projeto com:

- **YouTube Shorts**: título < 50 caracteres com a promessa do gancho + `#shorts`; descrição com 3–5 linhas,
  links oficiais citados no vídeo e 5–7 hashtags.
- **Instagram Reels**: primeira linha = gancho; lista curta com ✅/1️⃣; pergunta para comentar; 8–12 hashtags.
  Link não é clicável na legenda (mande para a bio).
- **TikTok**: uma frase de gancho + pergunta; 3–5 hashtags.
- **X**: até 280 caracteres; link numa resposta ao próprio post (o primeiro post com link perde alcance).

Em todas: marcar **conteúdo gerado/alterado por IA** (YouTube: "Uso de IA → Sim"; TikTok: "AI-generated content";
Instagram: rótulo de IA). O avatar e a voz são sintéticos, mesmo sendo da própria pessoa.

Publicar, preencher formulário de upload ou agendar só com pedido explícito do usuário — e confirme o
último clique (publicar/postar) antes de fazer.
